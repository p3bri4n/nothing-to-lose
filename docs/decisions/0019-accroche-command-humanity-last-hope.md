# 0019 — Accroche courte officielle : « Command humanity's last hope »

- **Date** : 2026-11-05
- **Statut** : décidée
- **Complète** : [0017](0017-accroche-le-speech.md) (le speech reste le texte long officiel).
- **Contexte** : la décision 0017 fixait le speech comme accroche officielle, sans formule courte en tête de visuel. Le key art ([0018](0018-image-principale-key-art.md)) porte déjà un sous-titre en anglais, « COMMAND HUMANITY'S LAST HOPE », qui n'avait pas été déclaré accroche.
- **Options présentées** : non consignées dans le compte rendu de la session (décision prise directement par l'utilisateur).
- **Recommandation des agents** : non consignée dans le compte rendu de la session.
- **Décision de l'utilisateur** : « le sous titre de l'image devient l'accroche officielle ».
  - Accroche courte officielle : le sous-titre du key art, « COMMAND HUMANITY'S LAST HOPE » (graphie en capitales sur l'image ; écriture courante : « Command humanity's last hope »).
  - Titre complet public : « Nothing To Lose — Command humanity's last hope ».
  - Le speech en français reste le texte long officiel ([0017](0017-accroche-le-speech.md)).
  - Précision de l'utilisateur (même date) : « commandez avec brio demeure pour la description ». « Commandez avec brio ! » reste la signature française de la description (dernière phrase du speech, texte long) ; « Command humanity's last hope » est l'accroche courte officielle.
- **Conséquences** :
  - l'accroche courte est en anglais ; elle ne reprend pas la signature « commandez avec brio ! », qui reste celle de la description (0017) ;
  - le titre public complet utilise l'accroche : « Nothing To Lose — Command humanity's last hope » ;
  - la graphie officielle sur les visuels reste celle de l'image (capitales), sauf décision contraire.
